## 🚀 ¿Cómo usar esta plantilla para tu entrega?

1. **Crea tu propia rama (*branch*)** en Git con el formato `entrega/CODIGO-APELLIDO-NOMBRE`.
2. **Copia los archivos base** a tu espacio de trabajo o impórtalos directamente a tu proyecto de Overleaf.
3. **Reemplaza el contenido** con los datos, análisis, ecuaciones y bibliografía de tu propio trabajo de investigación.
4. **Compila y verifica** que no existan errores ni advertencias (`warnings`) antes de subir tus cambios y abrir tu Pull Request.

Consulta la [Guía de Entregas y Branches](../evaluaciones/GUIA_DE_ENTREGAS_Y_BRANCHES.md) para ver los pasos detallados.

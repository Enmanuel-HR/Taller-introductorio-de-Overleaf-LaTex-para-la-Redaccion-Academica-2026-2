# 📗 Sesión 1: Introducción a LaTeX y Overleaf – Mi Primer Proyecto

## 🎯 Objetivo de la Sesión

Familiarizar al estudiante con el ecosistema LaTeX y la plataforma Overleaf, logrando crear y compilar su primer documento académico desde cero.

---

## 📖 Temas Abordados

1. **¿Qué es LaTeX y por qué usarlo?**
   - Diferencias entre procesadores de texto (Word) y sistemas de composición tipográfica (LaTeX).
   - Ventajas para la redacción académica: calidad tipográfica, automatización, reproducibilidad.

2. **Introducción a Overleaf**
   - Creación de cuenta y tour por la interfaz.
   - Crear un nuevo proyecto en blanco.
   - El panel de código, el panel de vista previa y el compilador.

3. **Estructura básica de un documento LaTeX**
   - `\documentclass{}`: clases de documento (`article`, `report`, `book`).
   - El **preámbulo**: carga de paquetes (`\usepackage{}`), configuración del idioma y codificación.
   - El **cuerpo** del documento: `\begin{document}` ... `\end{document}`.
   - Jerarquía de secciones: `\section{}`, `\subsection{}`, `\subsubsection{}`.

4. **Mi Primer Proyecto**
   - Ejercicio guiado paso a paso para crear un documento con título, autor, fecha, secciones y texto.

## 💻 Ejercicio de la Sesión

Crea un documento en Overleaf que contenga:
- Un título, autor y fecha.
- Al menos 3 secciones con subsecciones.
- Texto formateado con **negritas**, *cursivas* y listas.
- Compilación exitosa sin errores.

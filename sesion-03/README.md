# 📗 Sesión 3: Figuras, Tablas y Referencias Cruzadas

## 🎯 Objetivo de la Sesión

Que el estudiante domine la inserción y referenciación profesional de figuras y tablas en un documento LaTeX, incluyendo el uso de apéndices.

---

## 📖 Temas Abordados

1. **Inserción de figuras**
   - Paquete `graphicx` y comando `\includegraphics{}`.
   - Entorno flotante `figure`: posicionamiento (`[h]`, `[t]`, `[b]`, `[H]`).
   - `\caption{}` para títulos descriptivos.
   - `\label{}` para etiquetado y referenciación.
   - Organización de archivos: carpeta `imagenes/`.

2. **Creación de tablas**
   - Entorno `tabular`: columnas, alineación, líneas.
   - Entorno flotante `table` con `\caption{}` y `\label{}`.
   - Paquete `booktabs` para tablas profesionales (`\toprule`, `\midrule`, `\bottomrule`).
   - Herramientas online para generar tablas.

3. **Referencias cruzadas**
   - Sistema `\label{}` – `\ref{}` para figuras, tablas, ecuaciones y secciones.
   - Buenas prácticas de etiquetado: prefijos `fig:`, `tab:`, `eq:`, `sec:`.
   - Doble compilación para resolver referencias.

4. **Apéndices**
   - Comando `\appendix` para secciones complementarias.
   - Organización de material suplementario.

## 💻 Ejercicio de la Sesión

Modifica tu manuscrito para incluir:
- Al menos 2 figuras con `\caption` y `\label`.
- Al menos 1 tabla profesional con `booktabs`.
- Referencias cruzadas en el texto (e.g., "*como se observa en la Figura \ref{fig:ejemplo}*").
- Un apéndice con material complementario.

# 📗 Sesión 3: Entorno Integrado de Trabajo: Visual Studio Code, Git/GitHub y Copilotos de IA

## 🎯 Objetivo de la Sesión

Que el estudiante haga la transición del "piloto manual" al "piloto automático", configurando su propio entorno de desarrollo integrado (IDE) local con control de versiones profesional y asistencia de Inteligencia Artificial para la redacción científica.

---

## 📖 Temas Abordados

1. **Del Piloto Manual al Piloto Automático**
   - Limitaciones del editor web tradicional de Overleaf (timeouts, límites de compilación).
   - Introducción a la automatización del flujo de trabajo académico.

2. **Control de Versiones con Git y GitHub**
   - Conceptos clave desmitificados: *Working Directory*, *Staging Area* (`git add`), *Repository* (`git commit`).
   - Gestión de ramas (*branches*) y resolución de entregas académicas mediante *Pull Requests (PR)*.
   - Beneficios de **GitHub Education** con el correo institucional PUCP.

3. **Visual Studio Code como IDE Central**
   - Qué es un IDE y por qué centralizar el flujo de trabajo (unificación de \LaTeX, R, Python, Git y Zotero).
   - Paneles esenciales: Explorador, Extensiones, Terminal integrada y Esquema (*Outline*).
   - Terminales y entorno: PowerShell vs. CMD vs. Bash, y la variable `PATH`.

4. **Extensión Overleaf Workshop en VS Code**
   - Conexión por Cookies de sesión (`overleaf_session`) mediante herramientas de desarrollador (`F12`).
   - Sincronización en tiempo real, compilación y visor de PDF ilimitado.
   - Persistencia del entorno con Espacios de Trabajo (*Workspaces* `.code-workspace`).

5. **Copilotos de IA y Google Antigravity**
   - Modelos de lenguaje (Gemini, Claude, GPT) vs. Agentes de programación.
   - Modos de interacción en Antigravity (*Agent*, *Ask*, *Plan*).
   - Diagnóstico automático de terminales y variables de entorno.
   - Automatización de flujos de Git (commit, push, ramas) en lenguaje natural.
